使用边界

本产品目前是视觉算法原型，不是医疗器械。透明塑料反光、手机抖动、气泡、遮挡和低照度都可能造成误差；不得以本界面读数替代医护人员判断、输液泵报警或临床监护。

01
INSTALLATION

安装到手机

安装前先确认

手机需要打开一个 HTTPS 网址。电脑预览地址 127.0.0.1:4173 只能在这台电脑本机使用；在手机上输入它，会指向手机自己。要给手机安装，请先把本目录部署到 HTTPS 服务器。

iOSSafari
  1. 用 Safari 打开滴准的 HTTPS 地址。
  2. 点“分享”或“更多”，选择“添加到主屏幕”。
  3. 如页面提供“作为 Web App 打开”，将其启用。
  4. 点“添加”，以后从桌面图标启动。
AndroidChrome
  1. 用 Chrome 打开滴准的 HTTPS 地址。
  2. 点右上角“更多”。
  3. 选择“安装应用”或“添加到主屏幕”。
  4. 确认安装，从桌面图标启动。
HarmonyOS华为浏览器
  1. 用华为浏览器打开滴准的 HTTPS 地址。
  2. 点底部右侧菜单。
  3. 选择“添加至”→“桌面”。
  4. 按系统提示授权创建桌面快捷方式。

不同系统版本的菜单名称可能略有差异，详细步骤见文末官方参考。

02
FIRST MONITORING

完成第一次监测

  1. 固定手机

    优先使用手机支架，后置摄像头与滴管保持基本平行，避免手持晃动。

  2. 打开摄像头

    启动 App，选择“手机后置摄像头”，首次使用时允许摄像头权限。

  3. 对准滴管

    让滴嘴、液滴下落通道和液面上方透明区域清晰可见。

  4. 调整识别框

    拖动方框改变位置，拖右下角控制点调整大小；虚线检测门应横穿液滴路径。

  5. 开始监测

    点击“开始监测”，保持画面不动，等待校准并观察 3–5 滴后再读取结果。

补光建议

背景与液滴反差不足时可打开“补光”。若按钮不可用，说明当前手机或浏览器未向网页开放闪光灯控制。

03
POSITIONING

正确放置识别框

建议这样做
  • 只框住滴嘴到液面之间的透明通道
  • 让虚线横穿液滴的必经位置
  • 保持滴管居中、背景简单、光线均匀
  • 用支架固定手机与输液器
尽量避免
  • 识别框覆盖液面、塑料边缘或刻度文字
  • 背景有人走动、屏幕闪烁或窗外强光
  • 液面剧烈晃动或大量气泡经过
  • 画面失焦、过暗或高光反射严重

误报较多时，在“识别设置”中降低灵敏度；漏检时先改善取景和光线，再小幅提高灵敏度。

04
READINGS

读懂界面结果

实时滴速

最近多个有效液滴间隔估算出的每分钟滴数（滴/分）。

平均间隔

相邻有效液滴之间的代表性时间，单位为秒。

本次计数

本次开始监测后被算法接受的液滴事件数量。

稳定度

近期滴间隔的一致程度，只描述画面中的节律稳定性。

置信度

基于信号强度与规律性的算法内部参考，不等于医学精度或验证结论。

05
TEST MODE

用前序网页视频测试

可以。打开“切换画面”→“内置测试视频”，App 会加载前序网页使用的真实滴管素材。它适合检查界面、识别框、倍速切换和算法是否正常运行。

  1. 选择“内置测试视频”。
  2. 将识别框放到滴嘴下方的液滴通道。
  3. 点击“开始监测”，再到设置中切换 0.5×、1×、1.5×、2×。
  4. 确认读数能随倍速改变，并观察是否出现明显误报。
它不是精度标准

该视频没有逐帧人工标注的真实滴速，循环接缝、反光和气泡都可能形成运动信号。精度验证应使用已知滴速的装置同步拍摄并逐滴标注。

用两台设备联调

电脑打开 GitHub 上的滴液演示网页并播放画面，手机打开“摄像头检测”链接，对准电脑屏幕中的滴管区域。它适合验证完整的摄像头流程，但屏幕刷新与反光会影响读数，仍不属于精度校准。

06
TROUBLESHOOTING

常见问题

摄像头打不开

确认网址是 HTTPS；在浏览器的网站权限中允许摄像头；关闭可能占用摄像头的其他应用，然后刷新页面。手机上的 127.0.0.1 不是电脑地址。

一直显示“等待液滴”

重新调整识别框，让虚线通过液滴路径；增加光线或对焦；适当提高灵敏度，并确认视频确实在播放。

滴速跳动或计数过多

固定手机，缩小识别框，避开液面、气泡和塑料高光；降低灵敏度并等待几滴，让结果重新稳定。

找不到“安装”按钮

直接使用浏览器菜单：iOS 用 Safari 的“添加到主屏幕”，Android 用 Chrome 的“安装应用”，HarmonyOS 用华为浏览器的“添加至桌面”。

补光按钮不可用

部分 iPhone、浏览器或摄像头组合不向网页开放手电筒控制。这不影响基础监测，可改用环境灯或另一台设备补光。

07
PRIVACY & MAINTENANCE

隐私、离线与卸载

  • 本机处理：当前版本在设备浏览器内分析画面，不上传视频帧。
  • 离线使用：首次在线完整打开后，核心界面和内置测试素材会被缓存；摄像头能力仍取决于设备和浏览器。
  • 撤销权限：在浏览器的网站设置或系统隐私设置中关闭该站点的摄像头权限。
  • 卸载：长按桌面图标删除；HarmonyOS 若安装的是桌面快捷方式，删除只会移除快捷方式。
