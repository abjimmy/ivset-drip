# 滴准 App 安装与使用手册

手册版本：0.1  
更新日期：2026-08-30  
适用平台：iOS、Android、HarmonyOS

> **重要提示：** 当前版本是视觉滴速监测原型，不是医疗器械，也不是 App Store、APK 或 HAP 原生安装包。画面反光、手机抖动、气泡、遮挡和低照度都可能影响结果。不得用本产品读数替代医护人员判断、输液泵报警或临床监护。

## 1. 产品简介

滴准使用手机后置摄像头拍摄莫菲氏滴管，在设备本机分析用户框选区域内的运动峰值，估算：

- 实时滴速（滴/分）
- 平均滴间隔（秒）
- 本次有效液滴计数
- 近期节律稳定度
- 算法内部置信度

当前版本不会上传摄像头画面或视频帧。

## 2. 安装前准备

1. 一台带后置摄像头的 iPhone、Android 或 HarmonyOS 手机。
2. 稳定的手机支架，以及光线均匀、背景简单的拍摄环境。
3. 滴准的 **HTTPS 部署地址**。

### 关于本地预览地址

开发预览地址 `http://127.0.0.1:4173/drip-monitor-app/` 只能在运行服务器的那台电脑上使用。在手机浏览器中输入 `127.0.0.1` 会指向手机自己，而不是电脑。

摄像头网页还要求安全上下文。正式给手机使用前，应把 `drip-monitor-app` 和共用的 `assets` 目录部署到 HTTPS 服务器。

## 3. 安装到 iOS

1. 用 Safari 打开滴准的 HTTPS 地址。
2. 点“分享”或“更多”。
3. 选择“添加到主屏幕”。
4. 如果页面提供“作为 Web App 打开”，将其启用。
5. 点“添加”，以后从桌面图标启动。

官方说明：[Apple — 在 iPhone 上将网站作为 App 打开](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios)

## 4. 安装到 Android

1. 用 Chrome 打开滴准的 HTTPS 地址。
2. 点右上角“更多”。
3. 选择“安装应用”或“添加到主屏幕”。
4. 确认安装，从桌面图标启动。

官方说明：[Google Chrome — 在 Android 上使用 Web 应用](https://support.google.com/chrome/answer/9658361/use-progressive-web-apps-android?co=GENIE.Platform%3DAndroid&hl=zh-Hans)

## 5. 安装到 HarmonyOS

1. 用华为浏览器打开滴准的 HTTPS 地址。
2. 点底部右侧菜单。
3. 选择“添加至”→“桌面”。
4. 按系统提示授权创建桌面快捷方式。

不同系统版本的菜单名称可能略有差异。官方说明：[华为 — 浏览器添加网站至桌面快捷方式](https://consumer.huawei.com/cn/support/content/zh-cn00448896/)

## 6. 第一次使用

1. **固定手机：** 优先使用支架，后置摄像头与滴管基本平行。
2. **打开摄像头：** 启动滴准，选择“手机后置摄像头”。首次使用时允许摄像头权限。
3. **对准滴管：** 让滴嘴、液滴下落通道和液面上方透明区域清晰可见。
4. **调整识别框：** 拖动方框改变位置，拖右下角控制点改变大小。虚线检测门应横穿液滴路径。
5. **开始监测：** 点击“开始监测”，保持画面不动，等待校准并观察 3–5 滴后再读取结果。

## 7. 正确放置识别框

建议：

- 识别框只覆盖滴嘴到液面之间的透明通道。
- 虚线横穿液滴的必经位置。
- 滴管居中，背景尽量简单，光线均匀。
- 使用支架固定手机和输液器。

避免：

- 识别框覆盖液面、塑料边缘或刻度文字。
- 背景中有人走动、屏幕闪烁或窗外强光变化。
- 液面剧烈晃动或大量气泡经过。
- 画面失焦、过暗或有强烈高光反射。

误报较多时，在“识别设置”中降低灵敏度；漏检时应先改善取景和光线，再小幅提高灵敏度。

## 8. 指标说明

- **实时滴速：** 根据最近多个有效液滴间隔估算出的每分钟滴数。
- **平均间隔：** 相邻有效液滴之间的代表性时间。
- **本次计数：** 本次开始监测后被算法接受的液滴事件数量。
- **稳定度：** 近期滴间隔的一致程度，只描述画面中的节律稳定性。
- **置信度：** 基于信号强度与规律性的算法内部参考，不等于医学精度或验证结论。

## 9. 使用内置视频测试

前序网页的真实滴管视频可以作为测试素材：

1. 打开“切换画面”。
2. 选择“内置测试视频”。
3. 将识别框放在滴嘴下方的液滴通道。
4. 点击“开始监测”。
5. 在设置中切换 0.5×、1×、1.5×、2×，检查读数是否随倍速改变。

该视频适合界面、取景、循环播放、倍速和算法回归测试，但不应作为精度标准，因为它没有逐帧人工标注的真实滴速，循环接缝、反光与气泡也可能产生运动信号。正式精度验证应使用已知滴速的装置同步拍摄并逐滴标注。

### 用电脑网页作为手机摄像头测试目标

1. 在电脑浏览器打开 GitHub 上的滴液演示网页并开始播放。
2. 在手机浏览器打开“摄像头检测”直达链接。
3. 首次使用时允许后置摄像头权限；授权后会自动开始监测。
4. 将手机摄像头对准电脑屏幕中的滴管，调整识别框覆盖液滴路径。

这种方式能测试从网页、摄像头到滴速读数的完整流程，但显示器刷新、摩尔纹和反光会引入额外信号，只适合功能联调，不适合作为测量精度标准。

## 10. 常见问题

### 摄像头打不开

- 确认当前网址是 HTTPS。
- 在浏览器的网站权限中允许摄像头。
- 关闭可能占用摄像头的其他应用，再刷新页面。
- 不要在手机上使用电脑的 `127.0.0.1` 地址。

摄像头权限说明：[MDN — MediaDevices.getUserMedia()](https://developer.mozilla.org/zh-CN/docs/Web/API/MediaDevices/getUserMedia)

### 一直显示“等待液滴”

- 重新调整识别框，让虚线穿过液滴路径。
- 增加光线并确保滴管清晰对焦。
- 适当提高灵敏度。
- 测试模式下确认视频正在播放。

### 滴速跳动或计数过多

- 固定手机，避免手持晃动。
- 缩小识别框，避开液面、气泡和塑料高光。
- 降低灵敏度，等待数滴后重新观察。

### 补光按钮不可用

部分手机、浏览器或摄像头组合不会向网页开放手电筒控制。可使用环境灯或另一台设备补光，不影响其他功能。

### 找不到“安装”按钮

直接使用浏览器菜单：iOS 用 Safari 的“添加到主屏幕”，Android 用 Chrome 的“安装应用”，HarmonyOS 用华为浏览器的“添加至桌面”。

## 11. 隐私、离线与卸载

- **本机处理：** 画面在设备浏览器内分析，不上传视频帧。
- **离线使用：** 首次在线完整打开后，核心界面和内置测试素材会被缓存。
- **撤销权限：** 在浏览器的网站设置或系统隐私设置中关闭该站点的摄像头权限。
- **卸载：** 长按桌面图标删除。HarmonyOS 若安装的是桌面快捷方式，删除只会移除快捷方式。

## 12. 交付原生安装包时

若后续需要 App Store 包、Android APK/AAB 或 HarmonyOS HAP，需要分别准备开发者账号、应用标识、签名证书、相机权限说明和隐私政策。当前共用前端可作为 UI 与算法原型，但上架前还需要真机兼容测试、标注数据精度验证和合规评估。
